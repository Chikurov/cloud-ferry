# Флоу Cloud Ferry: разбор удобства

Состояние: ветка `main`, коммит с 0.2.1 (валидация до создания, создание папки, вход без OAuth).
Оценка трения: 1 — гладко, 5 — пользователь может не дойти до цели.

## 0. Запуск приложения

**Шаги:** открыть ярлык Umbrel → браузер запрашивает `/api/state` → отрисовка.

**Что видит:** спиннер и «Загрузка…», затем экран.

**Трение:**
- Если сервер отвечает медленно (SD-карта, холодный старт), нет подсказки, что происходит, и нет кнопки «Повторить» до истечения таймаута.
- При ошибке показывается отдельный экран «Нет связи с сервером» — это хорошо, но он полностью заменяет интерфейс: пользователь теряет контекст.

**Идеи:** показывать «Загружаем данные…» дольше 3 с; при офлайне оставлять последние данные, а сверху — полосу «нет связи».

## 1. Подключение диска (мастер)

**Шаги:** плитка «+» → шаг 1 «Подключение» → способ → логин и пароль приложения (или токен) → «Подключиться» → проверка доступа → шаг 2 «Папка на сервере» → «Обзор» или ручной путь → «Далее» → шаг 3 «Готово, диск подключён» → «Перейти к скачиванию».

**Что видит:** карточку с двумя способами, поля, подсказку про 360 и 2–3 часа, затем экран выбора папки и финальный экран с логином.

**Трение (3/5):**
- **Барьер входа.** Пароль приложения требует Яндекс 360. Без подписки остаётся только токен — это технический путь, обычный пользователь его не пройдёт.
- **Ожидание.** Пароль активируется 2–3 часа; человек вводит его сразу, получает ошибку и решает, что приложение сломано.
- **Токен.** Нужно создать OAuth-приложение, получить JSON с тремя полями. Без подготовки нереально.
- **Шаг 2 непонятен без контекста.** «Папка на сервере» — человек не знает, что это папка Umbrel, куда лягут файлы.
- **«Обзор» может быть недоступен**, если каталог не смонтирован; тогда остаётся ручной ввод пути.

**Идеи:**
- На шаге 1 крупно писать: «Нужна подписка Яндекс 360. Пароль начнёт работать через 2–3 часа» с кнопкой «Как получить пароль».
- Добавить третий путь «У меня нет 360» → инструкция по токену с картинками.
- На шаге 2 писать «Файлы появятся в папке Umbrel» и показывать свободное место рядом.
- Если проверка вернула `retryAfterHint`, предлагать «Напомнить через 2 часа» (пока просто текст).

## 2. Ошибки подключения

**Что видит:** сообщение под полями.

**Разбор:**
- Неверный пароль → «Неверный логин или пароль приложения». Хорошо.
- Пароль ещё не активен → «подождите 2–3 часа». Хорошо, но нет таймера и кнопки «проверить снова».
- Нет 360 → «WebDAV недоступен — нужен Яндекс 360». Понятно, но тупик: дальше некуда идти.
- Сервер не ответил → «Сервер не ответил — попробуйте ещё раз». Без деталей, ок.

**Трение:** после ошибки нет подсказки, что делать дальше, кроме повтора. Для «нет 360» нужен переход на токен.

## 3. Первый экран без аккаунта

**Шаги:** одна плитка «+».

**Плюс:** минимум решений, всё понятно.

**Трение:** нет.

## 4. Новое скачивание

**Шаги:** «Из облака» → диалог выбора папок → отметить → «Сохранить» → «На сервере» → «Обзор» → выбрать папку → «Скачать».

**Что видит:** дерево папок с чекбоксами, счётчик, чипы; затем дерево серверных папок.

**Трение (2/5):**
- **Два разных диалога с одинаковым видом.** В облаке — мультивыбор с чекбоксами, на сервере — обычная навигация. Легко запутаться, почему тут нельзя отметить несколько.
- **Создание папки спрятано** в подвале серверного диалога.
- **Лимит 20** не виден заранее — узнаёшь об ошибке после 21-й.
- **Нет оценки объёма до запуска**: человек не понимает, сколько качать и хватит ли места.
- **Режим копирования** убран с экрана — хорошо, но нет и слова о том, что файлы не удаляются; это узнаётся из README.

**Идеи:** показать «0 из 20»; добавить строку «Оценка объёма» (API уже есть); на серверном диалоге писать «Выберите папку» вместо «Выберите папки».

## 5. Активное скачивание

**Что видит:** процент, полоса, скорость, ETA, «Приостановить», источник и назначение.

**Плюс:** понятно и компактно.

**Трение:** нет. Но при неизвестном объёме процент 0 и полоса пустая — выглядит как зависание.

**Идея:** indeterminate-полоса и «Считаем объём…», пока `totalBytes = 0`.

## 6. Пауза и продолжение

**Шаги:** «Приостановить» → «Продолжить».

**Трение (2/5):** после перезапуска приложения задание становится «прерванным» с текстом «приложение перезапустилось», хотя это может быть пауза сервера. Кнопка «Продолжить» есть — это спасает.

## 7. Ошибка скачивания

**Что видит:** красный чип, заголовок, совет, «Не скачались: N», «Скопировать список», «Повторить».

**Трение (2/5):** список копируется в буфер, но не показывается — на телефоне проверить трудно. Нет ссылки «открыть папку».

## 8. Проверка подключения

**Шаги:** меню → «Проверить подключение».

**Плюс:** результат тостом, занятое место.

**Трение:** нет.

## 9. Выход из аккаунта

**Шаги:** меню → «Выйти» → подтверждение.

**Трение (2/5):** в диалоге сказано, что активное скачивание остановится, но не сказано, что станет с недокачанными файлами. После выхода аккаунт удаляется — вернуться можно только новым входом.

## 10. Хранилище

**Что видит:** две плитки — Яндекс Диск (занято/всего) и Сервер Umbrel (свободно/всего).

**Трение (2/5):** при недоступном облаке показывается «—», но без пометки «устарело». Если цифры старые, человек этого не поймёт.

## 11. Восстановление после перезапуска

**Что видит:** «прервано» и «Продолжить».

**Трение (3/5):** если задание успело завершиться, пока приложение было выключено, оно всё равно помечается прерванным — пользователь запускает повторно и качает заново.

## 12. Офлайн

**Что видит:** отдельный экран с «Повторить»; после возврата связи — приложение.

**Трение (2/5):** последние данные не сохраняются, интерфейс исчезает.

## Сквозные наблюдения

1. **Словарь.** Интерфейс говорит «скачивание», серверные ошибки иногда — «перенос». Уже частично исправлено, но backend ещё отдаёт старые формулировки.
2. **Один аккаунт.** После «Войти заново» предыдущий аккаунт удаляется, история заданий остаётся от старого — это может путать.
3. **Нет истории.** Сознательное решение, но после ошибки нельзя вернуться к прошлому заданию.
4. **Нет оценки объёма.** API есть, кнопки нет.
5. **Мобильный.** Все флоу те же, но диалоги занимают почти весь экран, а футер с кнопками переносится.

## Что предлагаю исправить в первую очередь

1. Экран входа: явно про Яндекс 360 и 2–3 часа + путь «нет 360» → токен.
2. Оценка объёма перед запуском (кнопка «Узнать объём», API готов).
3. Indeterminate-прогресс при неизвестном объёме.
4. Показ списка неудачных файлов (не только копирование).
5. Пометка «устарело» в хранилище, когда данные старые.
6. Разные заголовки диалогов: «Выберите папку» / «Выберите папки».
7. Счётчик лимита «0 из 20» рядом с выбором.
