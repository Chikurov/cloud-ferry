# Фоновый рефакторинг фронтенда: снимки состояний

Скриншоты сняты в headless Chrome (1000×820, DPR 2) на реальных
`internal/httpapi/web/{index.html,app.js,style.css}` с mock-API, который
воспроизводил сетевые сбои, ошибки сервера и смену статуса задания.
Проверки выполнялись через CDP: 23/23 прошли, ошибок JS на странице нет.

| Файл | Что показывает |
|---|---|
| `network-error.png` | Сетевой сбой `POST /api/jobs` (обрыв соединения) → баннер «Сервер не отвечает. Проверьте связь и повторите.», кнопка «Скачать» не остаётся busy |
| `dialog-error.png` | Ошибка `DELETE /api/accounts/…` (500) → inline-ошибка внутри открытого диалога «Сервис недоступен. Повторите позже.», диалог не закрывается |
| `focus-after-done.png` | Переход «Сейчас» running → done: фокус с исчезнувшей кнопки «Приостановить» переходит на заголовок региона (видимая рамка фокуса), объявление в `#live` одно |
| `folder-tree.png` | Дерево папок в пикере: настоящие вложенные списки (`ul.folder-tree` → `ul.folder-children`) сохраняют прежний вид и дают иерархию скринридеру |

Дополнительно в том же прогоне автоматически проверялись: маппинг кодов
401/403/409/429/5xx/сеть/таймаут без HTML и длинных тел, скрытие «1 ч 0 мин»,
NBSP в счётчике папок, очередь уведомлений при открытом диалоге, отсутствие
параллельных запросов опроса (max in flight = 1 при ответе 3 с и интервале 2,5 с).
