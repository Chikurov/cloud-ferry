# Разработка

Команды выполняются из корня проекта.

Для сборки нужен Go 1.24+. Для локального запуска — rclone, для контейнеров — Docker Compose. Архиватор использует Python 3.

```bash
make test       # тесты Go с детектором гонок
make build      # бинарник bin/cloudferry
make archive    # ../cloud-ferry-source.zip
```

Go использует системные каталоги кэша вне проекта. Посмотреть их можно командой

```bash
go env GOCACHE GOMODCACHE
```

Пути определяются настройками Go. Явные значения `GOCACHE` и `GOMODCACHE` в окружении имеют приоритет; для переносимой копии проекта задавайте их вне его каталога.

Если в прежней копии проекта остались `.gocache` и `.gomodcache`, их можно удалить. Go создаст необходимые данные при следующей сборке. Команда `make archive` автоматически исключает эти каталоги, бинарники, локальные данные, окружения, вложенные ZIP и служебные файлы macOS. Исходники, документация, демо и шаблон `.env.example` входят в архив. ZIP создаётся рядом с папкой проекта.

## Скриншоты README

Для съёмки нужны Python 3, Playwright, Pillow и Chromium. Устанавливайте зависимости в виртуальное окружение вне проекта:

```bash
python3 -m venv ../cloud-ferry-tools
. ../cloud-ferry-tools/bin/activate
python3 -m pip install playwright pillow
python3 -m playwright install chromium
python3 scripts/screenshots.py
```

Снимки сохраняются в `docs/readme/`. Главный экран представлен в обеих темах; галерея в README показывает остальные экраны в светлой теме. Тёмные варианты этих экранов сохраняются для проверки интерфейса.

Для воспроизводимой съёмки используются профиль `alex.demo`, фиксированные данные загрузок, окно 1100 × 800 и плотность 2×. Скрипт должен открывать экраны через элементы интерфейса и завершаться ошибкой при неверном состоянии или горизонтальном переполнении.

Демо должно использовать те же HTML, CSS и JavaScript, что и приложение. Подменяются только ответы API и демонстрационные данные. Демо собирается из рабочих `internal/httpapi/web/*` и `scripts/preview-demo.js`:

```bash
python3 scripts/build_preview.py          # записать preview.html
python3 scripts/build_preview.py --check  # ошибка, если демо устарело
```

Повторная генерация не меняет результат. Изменение рабочего HTML/CSS/JS или демо-транспорта обнаруживается `--check`. После правки интерфейса обновите демо и снимки.

Сохраняйте читаемость текста при сжатии. Ориентир — до 500 КБ на PNG. Браузеры, зависимости и временные файлы в исходный архив не входят.
