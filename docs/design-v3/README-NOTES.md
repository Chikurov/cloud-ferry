## 4. Спорное и что осталось

1. **`docs/USER-GUIDE.md` устарел.** Гайд описывает прежний интерфейс: мастер
   подключения из трёх шагов («Папка на сервере», «Готово, диск подключён»),
   переключатель «Показать уже скачанные», «ячейку Сейчас». README ссылается
   на гайд, как требует task-8, но гайд нужно обновить отдельной задачей —
   иначе ссылка ведёт на описание, которого в приложении уже нет.
2. **Скриншот снят до финальной полировки.** `docs/design-v3/screens/` снят
   18.11 в 19:59; после него task-7 добавляет явный переключатель темы и
   чистит мёртвый код, поэтому на актуальном экране в шапке будет ещё кнопка
   темы. Файл выбран потому, что task-8 разрешает скриншоты только из
   `docs/design-v2/` или `docs/design-v3/screens/`; новые `theme-v3-*.png` в
   корне репозитория не закоммичены и в область задачи не входят.
3. **`docs/design-v3/` ещё не в git.** README ссылается на файл из этой папки:
   после коммита дизайна v3 ссылка станет рабочей. Коммит не делался.
4. **Название «Новое скачивание» в интерфейсе не показывается.** Заголовок
   диалога — это название шага («Что скачать», «Сохранить на Umbrel»), поэтому
   README не ссылается на «Новое скачивание» как на видимую подпись.
5. **Ограничение про оценку объёма** («нельзя отменить на сервере, обход до
   10 минут») взято из `docs/ARCHITECTURE.md`. Оно техническое; если README
   должен быть строго пользовательским, пункт можно убрать.
6. **Старые скриншоты `docs/readme/*.png`** больше нигде не упоминаются, но
   файлы остались на месте: удаление вне области задачи.
7. Подписи сверялись по рабочей копии, пока task-7 (theme-cleanup-v3) ещё
   правит `internal/httpapi/web/*`; перед коммитом стоит перепроверить
   «Что скачать»/«Сохранить на Umbrel»/«Изменить» на финальной версии.
